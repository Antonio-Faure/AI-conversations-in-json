# AI Conversations in JSON

Extraction automatique de conversations IA (tous chatbots) en JSON standardisé.

## Objectif

Normaliser et unifier les exports de conversations IA dans un format JSON commun, quelle que soit la plateforme source (ChatGPT, Claude, Gemini, etc.).

## Plateformes cibles

- ChatGPT / OpenAI
- Claude / Anthropic
- Gemini / Google
- Perplexity
- Autres (à définir)

## Format de sortie

Le JSON standardisé contiendra :
- Métadonnées (date, modèle, plateforme)
- Messages (rôle, contenu, timestamp)
- Contexte (tokens utilisés, etc.)
